# Cynbit-Nexus AI

Cynbit-Nexus is a proof-of-concept AI engineering platform combining hybrid retrieval, query routing, Monte Carlo effort estimation, and a Streamlit dashboard.

> Evaluation results use a small synthetic corpus and are not production performance guarantees.

## Quick start

```bash
python -m pip install -r requirements.txt
python evaluate.py
streamlit run app.py
```

See `BENCHMARK_RESULTS.md` for reproducible evaluation output. Run tests with `pytest -q`.
